\# 🚚 LogiTrack



Sistema de gerenciamento logístico desenvolvido para organizar e controlar operações de estoque, produtos, pedidos, armazéns e entregas.



O projeto tem como objetivo aplicar conhecimentos de desenvolvimento Full Stack, utilizando Java com Spring Boot no backend e Angular no frontend.



\## 🛠️ Tecnologias utilizadas



\### Backend

\- Java 21

\- Spring Boot

\- Spring Data JPA

\- Hibernate

\- PostgreSQL

\- Maven

\- Lombok

\- Bean Validation



\### Frontend

\- Angular

\- TypeScript

\- HTML

\- CSS



\## 📦 Módulos do sistema



O projeto está organizado nos seguintes módulos:



| Módulo | Responsabilidade |

|---|---|

| User | Gerenciamento de usuários e suas permissões. |

| Product | Cadastro e gerenciamento de produtos. |

| Stock | Controle de estoque e quantidades disponíveis. |

| Warehouse | Gerenciamento de armazéns. |

| Order | Gerenciamento de pedidos. |

| Delivery | Controle e acompanhamento de entregas. |

\## 🎯 Objetivo do projeto



Desenvolver uma aplicação Full Stack que simule um sistema de gerenciamento logístico, trabalhando com relacionamentos entre entidades, regras de negócio, APIs REST, persistência de dados e integração entre frontend e backend.



O LogiTrack também tem como objetivo aprofundar os conhecimentos em Java, Spring Boot, Angular e desenvolvimento de aplicações escaláveis.
